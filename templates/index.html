How The Rule-Based Matching System Works

Deterministic, transparent evaluation replacing ambiguous job searches with structured feedback.

3-Tier Architecture
📝 1. Profile Creation

Enter Academic & Technical Skills

Graduates build profile records with their degree, college, passing year, and technical skills (Python, SQL, HTML, etc.).

⚙️ 2. Rule Matching

Deterministic Comparison

Backend systematically parses candidate skills and compares them against employer job criteria stored in SQLite.

📊 3. Match Score (%)

Mathematical Formula

Score (%) = (Matched Skills / Required Skills) × 100

💡 4. Skill Gap Guidance

Actionable Learning Path

Unmatched skills are isolated and paired with curated free learning resources and hands-on mini-project ideas.
